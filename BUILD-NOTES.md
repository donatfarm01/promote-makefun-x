Build notes for the Promote make.fun post on X entry.

What this entry is. The entry is a single post on X, not a program that
gets scored. The program in this repository only hands the post address to
the grader. Places go by the post score at the deadline, which is the
number of replies plus reposts plus quotes on the post. Views and likes
move nothing.

The post. Bosku posts it himself from the public account zhiver_04, as a
quote of the make.fun post about making your own bounty, with the photo
from this repository attached. The exact caption text lives in the file
named POST-CAPTION, and it is 201 characters long, inside the limit. It
carries the make.fun sponsor page address, a tag of the make.fun account,
the play code, and it ends with a question asking readers what bounty they
would launch first, because replies are part of the score.

The photo. The file named post-image is an original picture made in this
session: a friendly robot holding a trophy and coins, with the words Got a
task, Put a price on it, and the name make.fun written out in plain text.
No logo was redrawn and no press pack art was used. There is no video on
the post, so no end card applies.

The play code. The caption uses the play code from the Day One Day Seven
entry. The kit says this bounty has four codes of its own, answerable from
its play-code endpoint, so the parent should confirm this code is one of
the four for this bounty before Bosku posts. If it is not, the caption
must be updated with the right code first, because a post without one of
this bounty codes is refused.

What is still open. The file named POST holds a placeholder address,
because the post does not exist yet. After Bosku posts, the parent fills in
the real post address there. The program refuses a placeholder address on
purpose, so the entry cannot be submitted with it still in place.

How the program was checked. The first version copied the address file to
the output folder, and two runs produced identical bytes. The revised
version also checks that the address names a real X post, refuses the
placeholder with a clear message, and still copies a well-shaped address.
The caption length was counted, and the photo was looked at to confirm the
words on it read correctly.

What must stay true. The post must be made inside the bounty window, which
closes on the 26th of November 2026, and it must stay up and public until
the results are out. Only one entry per account is allowed, and the post
must not be entered by any other account first.
